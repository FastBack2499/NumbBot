

NumbBot - A Simple Discord Bot

NumbBot is a Discord bot built using Python, designed to automate various tasks within a Discord server. It supports modular functionality and can be easily extended with additional commands.

Features

Basic Discord bot functionality

Modular command setup using cogs

Easy to configure and extend


Getting Started

Prerequisites

Python 3.8+

discord.py library


Installation

1. Clone the repository:

git clone https://github.com/FastBack2499/NumbBot.git
cd NumbBot


2. Install dependencies:

pip install -r requirements.txt


3. Set up the configuration in config.py with your bot token.



Running the Bot

python RealBot.py

Customization

You can add new commands by adding Python files to the cogs/ folder and extending the bot's functionality.
